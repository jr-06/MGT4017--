# Clover Website Project

A multi-section front-end website prototype based on the supplied Clover wireframes.

## Files
- `index.html` — website pages and content
- `styles.css` — layout, styling and responsive homepage headline spacing
- `script.js` — interactive shopping bag, personalisation previews and contact form demo
- `assets/` — original supplied product/category images and the restored homepage gift-box background

## Run locally
Open `index.html` in a modern browser. No build step is required.

The homepage headline uses separate responsive line breaks and adjusted line-height/margins to prevent overlap. The original homepage gift-box photograph and the supplied product photographs are retained. The visible Shop Now button is part of the supplied homepage reference image and has a transparent clickable link positioned over it.

Checkout and contact submission are front-end demonstrations and are not connected to payment or email services.
